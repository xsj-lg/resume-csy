### 4.2 需求详细说明

#### `REQ-v0.1.19-001` 上传图片时复用本地解析服务

- `target_version`: `0.1.19`
- `requirement_id`: `REQ-v0.1.19-001`
- `status`: `CONFIRMED`
- `summary`: 上传图片简历时，不再限定为 PDF；图片文件走与 PDF 相同的本地解析服务接口，并将解析文本继续供规则初抽、结构化抽取和自动评分复用。
- `acceptance_criteria`:
  - 上传入口支持 `PDF/png/jpg/jpeg/bmp/gif/webp` 文件。
  - 图片文件上传后，服务端以同一 `file` multipart 字段调用 `http://127.0.0.1:7642/ais/parser/syncParseFile`，并按既有 `pages[].paragraphs[].textPara.content` 结构抽取文本。
  - 图片解析成功后，解析文本与原始返回结果继续写入 `candidate_files` 解析缓存，后续结构化抽取与自动评分优先复用。
  - 图片上传时若本地解析服务不可达、超时、返回异常状态、非法 JSON 或空结果，接口直接返回解析失败，不走 PDF 旧工具回退链路。
  - 既有 PDF 上传、PDF 解析缓存复用与 PDF 失败回退能力不回归。
