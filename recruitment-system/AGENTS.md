# AGENTS

## Working Contract

- 所有规则判定以 `docs/00-governance/` 为准。
- 开工先读取 `docs/docs-index.md`。
- 功能变更前必须确认 `req-00` 是否有对应需求条目。
- 进入执行的需求必须先平移到 `roadmap-00`，保持同一 `requirement_id`。
- 发布后必须同步更新 `roadmap-01`、`req-01`、`req-02`。

## Delivery Output

每次交付至少包含：

- 变更文件路径
- 对应 `requirement_id`
- `roadmap-00` 状态变化
- 是否涉及发布后回填

## Guardrails

- 不杜撰需求状态或发布事实。
- 若信息缺失，显式列出假设与阻塞。
- 仅修改与目标直接相关文件。
